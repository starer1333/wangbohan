## Development

使用原生 **HTML / CSS / JavaScript**，通过 **GitHub Pages** 发布，无需构建步骤。平滑滚动使用 Lenis；中文标题字体为本地加载的思源宋体。

```text
index.html       页面结构与中文内容
styles.css       基础样式与响应式布局
refinement.css   视觉与交互细节调整
app.js           滚动与项目交互
i18n.js          英文内容与语言切换
downloads.js     项目附件对应关系与下载入口
assets/          字体、依赖、许可证、简历和项目资料
```

在仓库根目录启动任意静态文件服务器。例如已安装 Python 时：

```bash
python -m http.server 4174
```

然后打开 `http://localhost:4174/`。
